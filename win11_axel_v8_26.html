Drivers esenciales
Instalar en este orden exacto antes de cualquier otra cosa
1

Chipset AMD

Lo primero. Le dice a Windows cómo hablar con el procesador, la RAM y el resto del hardware.

  • Bajar de amd.com → Drivers & Support
  • Buscar: Ryzen 5 5600G → Chipset
  • Instalar y reiniciar
2

Drivers AMD Adrenalin (GPU)

Instalar en modo Personalizado — nunca Express.

  • Bajar de amd.com → Radeon Graphics
  • Marcar solo: Display Driver y AMD Audio Driver
  • Desmarcar: AMD Link, AMD User Experience, ReLive, Ryzen Master SDK
  • Instalar y reiniciar → ejecutar Bloque 11 (Telemetría AMD) inmediatamente
3

Audio Realtek

Windows generalmente lo instala solo. Si no hay audio, verificar en Administrador de dispositivos si hay ! amarillo en Audio.

  • Driver oficial de la placa: ASRock B450M-HDV R4.0 — Drivers
  • O buscar: ASRock B450M-HDV R4.0 audio en Google
4

Impresora Brother

Conectar por USB antes de instalar el driver.

  • Bajar de Buscar driver DCP-T530DW en Google
  • Instalar paquete completo (driver + escáner)
5

Verificar dispositivos restantes

Win+X → Administrador de dispositivos. Buscar cualquier ! amarillo y resolver.

    Write-Host "`n  ┌─ $grupo " -ForegroundColor Cyan -NoNewline
    Write-Host ("─" * [Math]::Max(2, 46 - $grupo.Length)) -ForegroundColor DarkGray
    foreach ($s in $grupos[$grupo]) {
        $total++
        try {
            $svc = Get-Service -Name $s -EA Stop
            if ($svc.StartType -eq "Disabled") {
                Write-Host ("  │  — {0,-36} ya Disabled" -f $s) -ForegroundColor DarkGray
                $yaOk++; continue
            }
            Set-Service -Name $s -StartupType Disabled -EA Stop
            Stop-Service -Name $s -Force -EA SilentlyContinue
            Write-Host ("  │  ✔ {0,-36} → Disabled" -f $s) -ForegroundColor Green
            $ok++
        } catch [Microsoft.PowerShell.Commands.ServiceCommandException] {
            Write-Host ("  │  ⚠ {0,-36} no existe" -f $s) -ForegroundColor DarkGray
            $noExiste++
        } catch {
            Write-Host ("  │  ✘ {0,-36} ERROR: $($_.Exception.Message)" -f $s) -ForegroundColor Red
            $errores++
        }
    }
    Write-Host "  └────────────────────────────────────────────────" -ForegroundColor DarkGray
